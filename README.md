# NeuroForge — умный подбор подрядчиков

Рабочее демо кейса «Креативные индустрии» HackAlem AI (#79-lite).
По параметрам мероприятия сервис возвращает до трёх доступных подрядчиков,
цитату из каждого профиля и конкретные причины соответствия условиям.

## Быстрый запуск

Запускайте команды из корня репозитория. Нужен Python 3.11+; проверенное
окружение — Python 3.13 на macOS. Node.js и отдельная сборка интерфейса не нужны.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
python scripts/build_embeddings.py
NEUROFORGE_LLM_ENABLED=false python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Документация HTTP API — http://127.0.0.1:8000/docs.

Первый запуск загрузит мультиязычную модель sentence-transformers из Hugging Face.
Для этого нужен интернет и место под модель; холодный запуск не входит во время
ответа на запрос. Сервис прогревает модель до готовности HTTP API.
После скачивания можно запускать без сети:

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 NEUROFORGE_LLM_ENABLED=false python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

Для повторения зафиксированных версий на Python 3.13 используйте
`python -m pip install -c constraints-demo.txt -e ".[dev]"`.
Совместимость этого снимка с другими версиями Python и ОС отдельно не проверена.

## Что показать жюри

В интерфейсе есть пять готовых запросов. Они используют исходный датасет,
а не специально добавленные профили:

| Сценарий | Ожидаемый результат |
|---|---|
| Ведущий, Алматы, корпоратив, 13 октября, 2 млн ₸ | 3 карточки из 8 подходящих |
| Тот же запрос на 31 декабря | Другие подрядчики; 2 подходящих; объяснение занятости |
| Флорист, Алматы, свадьба, 7 ноября, 600 тыс. ₸ | 1 карточка с причиной неполной выдачи |
| Банкетный зал, Алматы, 31 декабря, 200 тыс. ₸ | NO_MATCH: каталог есть, условия не выполняются |
| Декоратор, Астана, 14 ноября | NO_CATEGORY: в этом городе нет категории |

Повторите первый запрос: порядок останется прежним. Раскройте «Как получился
этот список», чтобы показать воронку исключений и баллы.
Числа выше относятся к поставленным 66 профилям и текущей конфигурации.

Проверяемый прогон тех же сценариев с настоящей моделью, без внешних LLM:

```bash
python scripts/run_demo_queries.py
python -m pytest -q
```

Демо-скрипт проверяет ожидаемые исходы, повторяемость порядка, смену даты и
ориентир 10 секунд, возвращая ненулевой код при нарушении.
Тесты подменяют модели; они не требуют сети и API-ключей.
При локальном замере после прогрева запросы с брифом занимали около 0,13–0,16 с
без внешней LLM. Это замер на машине разработки, не гарантия для любого сервера.

## AI и проверяемые объяснения

- Локальные мультиязычные эмбеддинги сравнивают пожелания с описаниями.
- Жёсткие фильтры проверяют город, категорию, дату, бюджет, формат, часы и язык.
- Рейтинг считается кодом; при равных округлённых баллах порядок определяется ID.
- Каждая карточка получает цитату из своего профиля, в том числе без брифа.
- Опциональная LLM выбирает дополнительные акценты по разрешённым ID фактов.
  Ответ проходит строгую проверку JSON; свободный текст модели не показывается.
  Цитата и цена сохраняются независимо от её решения.

Без ключей всё работает на тех же данных и локальной модели. Чтобы включить
LLM, скопируйте `.env.example` в `.env`, заполните `OPENAI_API_KEY` и/или
`NVIDIA_API_KEY`, затем запустите сервис без `NEUROFORGE_LLM_ENABLED=false`.
OpenAI используется первым, NVIDIA — следующим при отказе.
Проверить этот режим можно командой `python scripts/run_demo_queries.py --llm`;
она делает внешние API-вызовы и может расходовать кредиты.

Объяснения обрабатываются параллельно. Общий бюджет ожидания LLM по умолчанию
3 секунды; ошибки, невалидные ответы и таймауты приводят к шаблону.
SQLite-кэш хранит только проверенный выбор фактов и учитывает промпт и модели.
Живые провайдеры не входят в автономный тестовый прогон.

## API

- `GET /` — интерфейс.
- `GET /health` — готовность, число профилей и режим объяснений.
- `GET /catalog` — справочники из данных и границы календаря.
- `GET /demo-scenarios` — пять примеров.
- `POST /recommend` — подбор.

```bash
curl -s http://127.0.0.1:8000/recommend \
  -H 'Content-Type: application/json' \
  -d '{"city":"Алматы","date":"2026-10-13","event_type":"корпоратив","category":"Ведущий","budget_kzt":2000000}'
```

Обязательны `city`, `date`, `event_type`, `category`, `budget_kzt`.
Опциональны `duration_h`, `language`, `brief`.
Три бизнес-исхода возвращаются с HTTP 200: `FOUND`, `NO_CATEGORY`, `NO_MATCH`.
Некорректные параметры и даты вне покрытия календаря дают HTTP 422 с объяснением.
`found_count` — число показанных карточек; `eligible_count` — число всех прошедших фильтры.

## Данные и ограничения

Исходные 66 профилей находятся в `data/raw/hackathon-dataset-anonymized.jsonl`.
Среди них уже есть 13 синтетических профилей организаторов; интерфейс их помечает.
Дополнения можно положить в `data/synthetic/extra_profiles.jsonl` с
`synthetic: true`. Дублирующиеся ID и отсутствие основного датасета останавливают запуск.

Календарь покрывает только 23.09–31.12.2026. За пределами этого окна неизвестную
доступность нельзя считать свободным днём. При замене датасета обновите
`NEUROFORGE_CALENDAR_START` и `NEUROFORGE_CALENDAR_END`.

Цена «от» — нижняя граница, а не итоговая смета. Проставленные при подготовке
города и цены отмечаются отдельно. Цитаты — заявления из профилей, не независимая
проверка опыта подрядчика. Если исходные сведения двух профилей одинаковы,
сервис сообщает об этом, не придумывая различий.
Без брифа семантический вес отключён; без языка и длительности остаётся
сортировка по запасу бюджета с разрешением равенств по ID.
Бронирования, уведомлений и автоматического изменения условий нет.

## Структура

```text
api/                 HTTP API и запуск сервиса
src/neuroforge/       загрузка, фильтры, скоринг, объяснения, LLM и кэши
ui/                  HTML, CSS и JavaScript без сборки
data/raw/            исходный каталог
data/synthetic/      необязательные дополнения
data/demo_queries.json  проверяемые сценарии демо
scripts/             подготовка эмбеддингов и прогон демонстрации
tests/               модульные проверки, API и регрессии
docs/architecture.md  устройство и принятые ограничения
```

Подробности — в [архитектуре](docs/architecture.md).
