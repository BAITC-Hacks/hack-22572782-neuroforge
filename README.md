# NeuroForge — умный подбор подрядчиков

HackAlem AI, кейс «Креативные индустрии» (#79-lite). Сервис принимает
параметры заказа мероприятия и возвращает до 3 карточек подрядчиков с
конкретным, невзаимозаменяемым объяснением, почему каждый здесь.

Полная архитектура: [`docs/architecture.md`](docs/architecture.md).

## Статус
Проект в разработке. Текущий этап — скелет модулей, обработка датасета
и реализация пайплайна впереди.

## Стек
- Python 3.11+, FastAPI, Pydantic
- Эмбеддинги: `sentence-transformers` (локально, мультиязычно)
- LLM объяснений: Claude API (temperature=0, с кэшем и шаблонным fallback)

## Структура проекта
```
src/neuroforge/   — ядро пайплайна (фильтры, скоринг, объяснения)
api/               — FastAPI-обвязка
ui/                — минимальный демо-интерфейс
scripts/           — предпосчёт эмбеддингов, генерация синтетических профилей, демо-сценарии
tests/             — pytest, включая проверку детерминизма
data/raw/          — исходный датасет (не редактируется)
data/synthetic/    — добавленные синтетические профили
docs/              — архитектура и обоснования для жюри
```

## Демо-сценарии
1. Плотная категория, осенняя дата.
2. Редкая категория (3 профиля).
3. Запрос без результата.
