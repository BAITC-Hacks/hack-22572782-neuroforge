# Демонстрация для жюри за три минуты

## Название и описание для формы сдачи

**Название:** NeuroForge — объяснимый подбор event-подрядчиков.

**Описание:** AI-сервис помогает выбрать до трёх подрядчиков из существующего
каталога Казахстана. Учитывает город, дату, формат, бюджет, язык и длительность;
локальная мультиязычная модель сопоставляет пожелания с описаниями. Каждая
карточка содержит конкретное объяснение и цитату из профиля. Сервис различает
отсутствующую категорию и отсутствие подходящих кандидатов, показывает причины
отсева и сохраняет порядок при повторном запросе. Основной сценарий запускается
без API-ключей; внешняя LLM опционально выбирает акценты из проверенных фактов.
В репозитории — интерфейс, API, исходный датасет, тесты и пять демо-сценариев.

**Репозиторий:** https://github.com/BAITC-Hacks/hack-22572782-neuroforge

## Подготовка

Запустите `uv run --frozen --extra dev python run.py --check` заранее:
модель должна быть скачана до защиты. Затем запустите `uv run --frozen python run.py`
и откройте http://127.0.0.1:8000. Для режима с внешней LLM добавьте `--llm` и
укажите свои ключи в `.env`. Начните с проверенного автономного режима.

## 0:00–0:25 Проблема и результат

«Заказчик уже знает город и категорию. Мы помогаем выбрать из существующего
каталога: показываем до трёх свободных подрядчиков и объясняем, чем каждый
соответствует запросу. Каждое объяснение опирается на цитату и конкретные
условия. В каталоге 66 анонимизированных профилей, синтетические помечены».

## 0:25–1:15 Плотная категория и смена даты

Нажмите «Ведущий на корпоратив». Обратите внимание на три разные цитаты,
цены «от» и пожелания к ведущему. Повторите запрос — порядок сохраняется.
Раскройте «Как получился этот список»: видно число оставшихся на каждом этапе.

Нажмите «Тот же запрос в декабре». Появятся другие имена и два варианта.
Покажите текст: часть ведущих занята, ещё один не принимает формат мероприятия.
Календарь влияет на выдачу и это явно объяснено пользователю.

## 1:15–2:00 Редкий и пустые случаи

«Редкая категория · флорист» даёт один вариант и объясняет, почему не три.
«Никто не подходит» показывает существующий каталог банкетных залов, где
кандидаты заняты или дороже бюджета. «Категории нет в городе» показывает
отсутствие декораторов в Астане. Подчеркните различие двух пустых исходов.

## 2:00–2:40 Что происходит внутри

«Обязательные условия проверяет код. Локальная мультиязычная модель сравнивает
бриф с описаниями. Рейтинг фиксирован, при равенстве баллов используется ID.
Внешняя LLM опционально выбирает акценты из разрешённого меню фактов; она
не может изменить цену, добавить кандидата или обещать бронирование.
В трассировке видно, использованы LLM, кэш или резервные факты».

Если демонстрируете LLM, не называйте ответ из кэша новым внешним вызовом.
NVIDIA до исправления авторизации не следует представлять как работающую интеграцию.

## 2:40–3:00 Воспроизводимость и ценность

Покажите README, зелёные проверки и команду `run.py --check`.
«Жюри может запустить весь основной сценарий без API-ключей. Мы снижаем
время сравнения подрядчиков, сохраняя объяснимость и честные ограничения данных».

## Перед сдачей

- Отправьте итоговый код в репозиторий команды.
- На платформе откройте кейс и нажмите «Сдать решение»; GitHub push этого не заменяет.
- Укажите название и описание проекта, ссылку на репозиторий.
- Локальный адрес 127.0.0.1 доступен только на вашей машине: это не публичный deployment.
- Не добавляйте `.env` и API-ключи в репозиторий или материалы презентации.
